## Environment Configuration

To run Client Portal with full payment processing and billing checks, configure the following environment variables in your local `.env` or deployment runtime:

```bash
# The port and host for Fastify backend server
PORT=5330
HOST=127.0.0.1

# Stripe integration keys (required for Stripe setup and subscriptions)
STRIPE_SECRET_KEY=your_stripe_test_secret_key
STRIPE_PUBLISHABLE_KEY=your_stripe_test_publishable_key
STRIPE_WEBHOOK_SECRET=your_stripe_local_webhook_secret

# OpenRouter credentials (for AI assistant features)
OPENROUTER_API_KEY=your_openrouter_api_key

# Cookie session credentials
AUTH_SECRET=a_secure_cookie_session_secret_at_least_32_chars
```

## First Launch Sequence

When Client Portal starts up for the first time, it performs a touchless provisioning check:

1. **Stripe Price Synchronization**: The app connects to the Stripe API and creates products and monthly pricing records matching the plans listed above.
2. **Operator Registration**: The system provisions a Stripe Customer matching `DEMO_USER_EMAIL` (defaulting to `owner@example.com`).
3. **Starter Subscription**: An initial subscription is automatically created for the operator customer subscribing them to the first paid tier (e.g. `pro`).
4. **Database Table Creation**: The server configures its local SQLite WAL database and runs the table generation migrations.
