# Factory SaaS Smoke Deployment

This app was generated by `@vibetech/factory:saas`.

## Local ship preflight

Run this before attempting a live deploy:

```powershell
pnpm nx run factory-saas-smoke:ship:check
```

What it proves locally:
- shared packages build cleanly
- frontend and API compile cleanly
- the compiled API passes health/auth/pro-route smoke checks
- missing Stripe or deploy credentials are reported explicitly

## Deployment shape

- Frontend: Vercel static Vite deployment
- Backend: Railway Fastify deployment
- Billing: Stripe Checkout in test mode first

## Required environment variables

### Backend

```env
PORT=5320
HOST=0.0.0.0
APP_BASE_URL=https://factory-saas-smoke.your-domain.com
AUTH_SECRET=
DEMO_USER_EMAIL=
DEMO_USER_PASSWORD=
DEMO_USER_NAME=
STRIPE_SECRET_KEY=
RESEND_API_KEY=
SENTRY_DSN=
```

### Frontend

```env
VITE_API_BASE_URL=https://factory-saas-smoke-api.your-domain.com
VITE_POSTHOG_KEY=
VITE_POSTHOG_HOST=
VITE_STRIPE_PUBLIC_KEY=
SENTRY_DSN=
```

## Railway backend steps

1. Deploy from the monorepo root.
2. Use [railway.json](./railway.json).
3. Set the backend environment variables above.
4. Confirm `GET /api/health` returns `{"ok":true,"app":"factory-saas-smoke"}`.
5. Confirm `GET /api/billing/demo-checkout` returns a Stripe Checkout URL once `STRIPE_SECRET_KEY` is set.

## Vercel frontend steps

1. Import the repo in Vercel.
2. Set the project root to `apps/factory-saas-smoke`.
3. Build command: `pnpm run build`
4. Output directory: `dist`
5. Set the frontend environment variables above.
6. Use [vercel.json](./vercel.json) so `/terms` and `/privacy` resolve to the SPA entry.
