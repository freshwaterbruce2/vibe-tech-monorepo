# Vibe Tutor store listing — release candidate 1.5.13

Vibe Tutor is a teen-focused study organizer with optional Tutor and Buddy AI chats, schedules, focus tools, and gaming-themed rewards. It is for ages 13–17 and supports school organization; it is not medical treatment.

Proposed US price, held pending separate approval: **$2.99 one-time purchase**. The purchase includes up to **200 successful AI responses per UTC month**, capped at **30 per UTC day**. Core non-AI features continue when the allowance is used. No ads and no subscriptions.

Tutor explains school concepts and problem-solving. Buddy supports life, gaming, emotions, and social skills, and points schoolwork to Tutor. AI requires internet. Optional voice features use transcript text, not stored microphone audio.

Privacy-policy publication, Play Console configuration, pricing, screenshots, and submission remain blocked pending separate approval.
