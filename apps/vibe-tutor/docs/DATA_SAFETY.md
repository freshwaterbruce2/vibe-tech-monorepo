# Data Safety working sheet — do not submit without approval

Verify every Console selection from the runtime and [canonical policy](../privacy-policy.json) before saving. Vibe Tutor does not create app accounts. App data, AI chat history, and settings are local until app data is cleared or the app is uninstalled. AI message/context is processed only when the teen uses Tutor or Buddy. A keyed pseudonymous installation identifier supports entitlement and quota. Operational metadata is minimized; routine logs do not include chat text. Optional report text is opt-in and carries a 30-day expiration timestamp; automatic deletion depends on cloud TTL enforcement. TTL enforcement is unverified for this release. Voice workflows may send selected transcript text, not audio. Data Management export, import, and reset are incomplete and must not be declared as verified device-file backup or restore. No ads or sale of personal data.

Play Integrity/licensing and cloud/provider disclosures must be selected only after the exact production configuration is reviewed. Console changes are Blocked pending approval.
