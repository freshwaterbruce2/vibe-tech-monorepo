# vibe-hermes-control

This project is a React and Vite-based application that acts as a mission control dashboard for the Hermes Agent in the VibeTech Monorepo.

## Getting Started

### Development
```bash
pnpm nx dev vibe-hermes-control
```

### Build
```bash
pnpm nx build vibe-hermes-control
```

### Testing
```bash
pnpm nx test vibe-hermes-control
```
