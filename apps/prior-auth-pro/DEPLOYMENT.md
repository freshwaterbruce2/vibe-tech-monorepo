## Railway backend steps

1. Deploy from the monorepo root.
2. Use [railway.json](./railway.json).
3. Set the backend environment variables above.
4. Confirm `GET /` returns API metadata with the Vercel frontend URL.
5. Confirm `GET /api/health` returns `{"ok":true,"app":"prior-auth-pro"}`.
6. Confirm `GET /api/billing/demo-checkout` returns a Stripe Checkout URL once `STRIPE_SECRET_KEY` is set.

## Vercel frontend steps

1. Import the repo in Vercel.
2. Set the project root to `apps/prior-auth-pro`.
3. Enable source files outside the root directory so pnpm workspace packages are available.
4. Install command: `cd ../.. && pnpm install --force --no-frozen-lockfile --filter ./apps/prior-auth-pro...`
5. Build command: `pnpm run build`
6. Output directory: `dist`
7. Set `VITE_API_BASE_URL` to the Railway API URL.
8. Set the remaining frontend environment variables above.
9. Use [vercel.json](./vercel.json) so `/terms` and `/privacy` resolve to the SPA entry.
