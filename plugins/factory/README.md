# factory

Nx app factory plugin for `@vibetech/workspace`.

Current generators:

- `@vibetech/factory:saas`
- `@vibetech/factory:tauri-app`
- `@vibetech/factory:landing-only`

This plugin is the Phase 2 scaffold for the app-factory goal. It lives in `plugins/factory`
so it can participate both as an Nx generator package and as a workspace-local plugin surface.
